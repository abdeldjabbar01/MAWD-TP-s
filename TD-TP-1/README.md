**Student:** Abdeldjabbar Abba

## Project description
A clean, simple and responsive personal portfolio whose layout follows the Color Hunt interface: fixed header, a sticky side navigation (a bottom tab bar on phones) and layered color-band project cards. It presents who I am, my skills, projects, education and experience, and how to contact me. It works on desktop, tablet and smartphone.

## Technologies used
- HTML5 (semantic elements: `header`, `nav`, `main`, `section`, `article`, `figure`, `footer`)
- CSS3 (custom properties, Grid, Flexbox, media queries, dark mode)
- JavaScript (vanilla, DOM manipulation, events)
- Visual Studio Code, Chrome/Firefox DevTools, Git and GitHub

## Implemented features
- Sections: Home, About, Skills, Projects, Experience and education, Contact
- Light and dark mode toggle, saved between visits (defaults to the system setting)
- Skills grouped by category (AI, Programming, Research and data, Tools, Soft skills)
- Project cards with layered color bands (tech names appear on hover)
- Responsive layout: side navigation on desktop, bottom tab bar on phones
- Navigation highlights the section being viewed (IntersectionObserver)
- Contact form with live validation and accessible error messages
- Accessibility: skip link, visible focus, ARIA labels, reduced-motion support
